# 🎓 Web Programming Class Portfolio Project

This is a **portfolio website** I built for my **Web Programming class**. I decided to create a comprehensive personal portfolio that showcases modern web development skills and serves as both a class project and a real-world application.

## 📖 About This Project

This portfolio demonstrates full-stack web development using modern technologies and best practices. It's a complete content management system (CMS) that allows me to manage my projects, blog posts, and showcase my work professionally.

### 🎯 Project Goals
- **Academic**: Fulfill web programming class requirements
- **Professional**: Create a real portfolio for career opportunities  
- **Technical**: Learn and implement modern web technologies
- **Practical**: Build something I can actually use and maintain

## 🛠️ Technologies Used

### Backend
- **Laravel 11** - PHP framework for robust backend development
- **PHP 8.3** - Modern PHP with latest features
- **SQLite/PostgreSQL** - Database management
- **Laravel Fortify** - Authentication system
- **Spatie Media Library** - File upload and management

### Frontend  
- **React 18** - Component-based UI library
- **TypeScript** - Type-safe JavaScript development
- **Inertia.js** - Server-side rendering with SPA experience
- **Tailwind CSS** - Utility-first CSS framework
- **Headless UI** - Accessible UI components

### Features Implemented
- ✅ **Blog System** - Rich text editor, categories, tags
- ✅ **Project Showcase** - Image uploads, technology tags
- ✅ **Admin Dashboard** - Full CRUD operations
- ✅ **Contact Form** - Email integration with Gmail
- ✅ **Authentication** - Secure admin access
- ✅ **Responsive Design** - Mobile-first approach
- ✅ **SEO Optimized** - Meta tags, structured URLs
- ✅ **File Management** - Image uploads and processing
